# Quiz Odds Battle - Google連携セットアップガイド

## 全体構成

```
参加者 → Google フォーム → スプレッドシート → GAS API → React ダッシュボード
         (チーム名+回答)   (自動記録)         (JSON返却)   (オッズ表示)
```

## 手順

### Step 1: Google スプレッドシートを作成

1. [Google スプレッドシート](https://sheets.google.com) で新規作成
2. 名前: 「Quiz Odds Battle」など任意

### Step 2: Google フォームを作成

1. [Google フォーム](https://forms.google.com) で新規作成
2. フォーム名: 「クイズ回答フォーム」など任意

**フィールド1: チーム名**
- 質問タイプ: **プルダウン**
- 質問テキスト: `チーム名` (この名前が重要)
- 選択肢:
  - チーム1
  - チーム2
  - チーム3
  - チーム4
  - チーム5
- 必須に設定 ✓

**フィールド2: 回答**
- 質問タイプ: **ラジオボタン**
- 質問テキスト: `回答` (この名前が重要)
- 選択肢:
  - A
  - B
  - C
  - D
- 必須に設定 ✓

> **重要**: 質問テキストは `チーム名` と `回答` に正確に一致させてください。
> GAS コードの `TEAM_COLUMN` と `ANSWER_COLUMN` がこの名前で列を検索します。

### Step 3: フォームをスプレッドシートに連携

1. フォームの「回答」タブを開く
2. 「スプレッドシートにリンク」をクリック
3. 「既存のスプレッドシートを選択」→ Step 1 で作成したシートを選択
4. シート名が「フォームの回答 1」になることを確認

> シート名が異なる場合は `Code.gs` の `SHEET_NAME` を変更してください。

### Step 4: GAS をデプロイ

1. スプレッドシートで **拡張機能** → **Apps Script** を開く
2. エディタの `コード.gs` の中身をすべて削除
3. `gas/Code.gs` の内容をコピー＆ペースト
4. **保存** (Ctrl+S)
5. **デプロイ** → **新しいデプロイ**
6. 種類: **ウェブアプリ**
7. 設定:
   - 説明: 「Quiz Odds Battle API」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
8. **デプロイ** をクリック
9. 表示される **ウェブアプリURL** をコピー

### Step 5: React アプリに接続

プロジェクトルートに `.env` ファイルを作成:

```
VITE_GAS_URL=https://script.google.com/macros/s/XXXXX/exec
```

> `XXXXX` の部分をStep 4でコピーしたURLに置き換え

GitHub Pages にデプロイする場合は、リポジトリの Settings → Secrets and variables → Actions → Variables で `VITE_GAS_URL` を設定し、deploy.yml の build ステップに環境変数を追加:

```yaml
- run: npm run build
  env:
    VITE_GAS_URL: ${{ vars.VITE_GAS_URL }}
```

### Step 6: 動作確認

1. `npm run dev` でローカル起動 (GAS URL設定済みなら本番接続)
2. `?admin=true` で管理パネルを表示
3. 「回答開始」ボタンを押す → GAS に問題開始が通知される
4. Google フォームから回答を送信
5. 5秒後のポーリングでダッシュボードに回答が反映されることを確認

## イベント当日の運用フロー

```
1. 管理者がダッシュボード (?admin=true) をプロジェクターに投影
2. 参加者にフォームのURLまたはQRコードを共有

 問題ごとのループ:
3. 管理者: 問題文を読み上げ
4. 管理者: 「▶ 回答開始」をクリック
   → フォームで回答受付
   → ダッシュボードにリアルタイムでオッズ表示
5. 参加者: フォームから「チーム名」と「回答(A/B/C/D)」を送信
   ※ 同じチームが複数回送信した場合は最新の回答が有効
6. 全チーム回答後、管理者: 「🎯 正解発表」をクリック
   → 紙吹雪エフェクト + 正解ハイライト + スコア更新
7. 管理者: 「次の問題 ▶」をクリック
8. 3に戻る
```

## チーム名・チーム数の変更

チーム構成を変更する場合、以下3箇所を同時に編集:

1. **Google フォーム**: 「チーム名」のプルダウン選択肢
2. **gas/Code.gs**: `TEAM_MAP` オブジェクト
3. **src/data/questions.js**: `teams` 配列

## トラブルシューティング

### 「Column not found」エラー
→ フォームの質問テキストと `Code.gs` の `TEAM_COLUMN` / `ANSWER_COLUMN` が一致しているか確認

### GAS から回答が返ってこない
→ GAS ウェブアプリの「アクセスできるユーザー」が「全員」になっているか確認
→ GAS を再デプロイ (新しいデプロイを作成する必要あり)

### CORS エラー
→ `fetch` で `Content-Type` ヘッダーを設定していないことを確認 (api.js は対応済み)
→ GAS は `doPost` を使用し、Content-Type なしの POST で呼び出す
